# StudyCardScreen UseCases

## ユースケース1: 出題カードを確認する

### 基本フロー

1. ユーザーは学習カード画面を表示する。
2. システムはローディング状態を表示する。
3. システムは出題カードを読み込む。
4. システムはローディング状態を非表示にする。
5. システムは出題カードを表示する。
6. システムは進捗情報を表示する。

### 例外フローA: 出題カード読み込みに失敗する（基本フロー3から分岐）

3-A. システムは出題カード読み込みエラーを検知する。
4-A. システムはローディング状態を非表示にする。
5-A. システムはエラーアラートを表示する。

## ユースケース2: 正解として判定する

### 基本フロー

1. ユーザーは出題カードを右スワイプする。
2. システムは正解判定を記録する。
3. システムは次の出題カードを表示する。

### 分岐フローA: 最後の1問を判定した（基本フロー2から分岐）

2-A. システムは学習結果を集計する。
3-A. システムは成績詳細画面へ遷移する。

### 例外フローB: 判定保存に失敗する（基本フロー2から分岐）

2-B. システムは判定保存エラーを検知する。
3-B. システムはエラーアラートを表示する。
4-B. システムは次の出題カードを表示する。

## ユースケース3: 不正解として判定する

### 基本フロー

1. ユーザーは出題カードを左スワイプする。
2. システムは不正解判定を記録する。
3. システムは次の出題カードを表示する。

### 分岐フローA: 最後の1問を判定した（基本フロー2から分岐）

2-A. システムは学習結果を集計する。
3-A. システムは成績詳細画面へ遷移する。

### 例外フローB: 判定保存に失敗する（基本フロー2から分岐）

2-B. システムは判定保存エラーを検知する。
3-B. システムはエラーアラートを表示する。
4-B. システムは次の出題カードを表示する。

## ユースケース4: 問題面と答え面を切り替える

### 基本フロー

1. ユーザーは出題カードを長押しする。
2. システムはカード表示面を切り替える。

## UI要素

- 出題カード
- 進捗ラベル
- ローディングインジケータ
- エラーアラート

## UI状態

- 現在出題カード
- 現在出題番号
- 合計出題数
- カード表示面状態
- ローディング表示状態
- エラーアラート表示状態

## UIイベント

- 基本フロー1「出題カードを右スワイプする」: 出題カードを右スワイプする
- 基本フロー1「出題カードを左スワイプする」: 出題カードを左スワイプする
- 基本フロー1「出題カードを長押しする」: 出題カードを長押しする
