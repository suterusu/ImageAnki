# StudySessionScreen UseCases

## ユースケース1: 学習セッションを開始して問題カードを表示する
### 基本フロー
1. ユーザーは学習セッション画面を表示する。
2. システムはローディング状態を表示する。
3. システムは開始済み学習セッションの現在カード情報を読み込む。
4. システムはローディング状態を非表示にする。
5. システムは現在カード画像を表示する。
6. システムは進捗情報を表示する。

### 例外フローA: 学習セッションの読み込みに失敗する（基本フロー3から分岐）
3-A. システムは学習セッション読み込み時にエラーを検知する。
4-A. システムはローディング状態を非表示にする。
5-A. システムはエラーアラートを表示する。
6-A. システムは処理を終了する。

## ユースケース2: 現在カードの判定結果を入力する
### 基本フロー
1. ユーザーは現在カードの判定結果を入力する。
2. システムは入力された判定結果を現在カードへ記録する。
3. システムは残り出題数を再計算する。
4. システムは次カード画像を表示する。
5. システムは更新済み進捗情報を表示する。

### 分岐フローA: セッションの最終カードを判定する（基本フロー3から分岐）
3-A. システムは残り出題数が0件であることを検知する。
4-A. システムは学習セッション結果を保存する。
5-A. システムは成績一覧画面へ遷移する。

### 例外フローB: 判定結果の保存に失敗する（基本フロー2から分岐）
2-B. システムは判定結果保存時にエラーを検知する。
3-B. システムはエラーアラートを表示する。
4-B. システムは処理を終了する。

## ユースケース3: カードの表示内容を切り替える
### 基本フロー
1. ユーザーは現在カードの表示内容切り替えを要求する。
2. システムは現在カードを問題表示から意味表示へ切り替える。

### 分岐フローA: 現在カードが意味表示である（基本フロー1から分岐）
1-A. システムは現在カードが意味表示であることを検知する。
2-A. システムは現在カードを意味表示から問題表示へ切り替える。

## UI要素
- 問題カード画像
- 進捗表示ラベル
- ローディングインジケータ
- エラーアラート

## UI状態
- 現在カードID
- 現在カード表示種別
- 現在カード画像
- 進捗情報
- ローディング表示状態
- エラーアラート表示状態

## UIイベント
- 基本フロー1「学習セッション画面を表示する」: 画面遷移後に表示イベントを発火する
- 基本フロー2「現在カードの判定結果を入力する」: 現在カードを右スワイプまたは左スワイプする
- 基本フロー3「現在カードの表示内容切り替えを要求する」: 現在カードを長押しする
