# PerformanceListScreen UseCases

## ユースケース1: 学習成績一覧を確認する
### 基本フロー
1. ユーザーは成績一覧タブを開く。
2. システムはローディング状態を表示する。
3. システムは学習成績一覧を読み込む。
4. システムはローディング状態を非表示にする。
5. システムは学習成績概要リストを表示する。

### 分岐フローA: 学習成績が0件である（基本フロー3から分岐）
3-A. システムは学習成績が0件であることを検知する。
4-A. システムはローディング状態を非表示にする。
5-A. システムは空状態メッセージを表示する。

### 例外フローB: 学習成績一覧の読み込みに失敗する（基本フロー3から分岐）
3-B. システムは学習成績一覧読み込み時にエラーを検知する。
4-B. システムはローディング状態を非表示にする。
5-B. システムはエラーアラートを表示する。
6-B. システムは処理を終了する。

## ユースケース2: 学習成績詳細を表示する
### 基本フロー
1. ユーザーは学習成績概要を選択する。
2. システムは選択した学習回IDの成績詳細画面へ遷移する。

## UI要素
- 学習成績リスト
- 学習成績セル
- ローディングインジケータ
- 空状態メッセージ
- エラーアラート

## UI状態
- 学習成績概要一覧
- 選択中学習回ID
- ローディング表示状態
- 空状態表示状態
- エラーアラート表示状態

## UIイベント
- 基本フロー1「成績一覧タブを開く」: 成績一覧タブをタップする
- 基本フロー2「学習成績概要を選択する」: 学習成績セルをタップする
