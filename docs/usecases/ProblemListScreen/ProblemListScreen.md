# ProblemListScreen UseCases

## ユースケース1: 学習履歴一覧を確認する
### 基本フロー
1. ユーザーは成績一覧タブを開く。
2. システムはローディング状態を表示する。
3. システムは学習履歴一覧を読み込む。
4. システムはローディング状態を非表示にする。
5. システムは履歴概要の一覧を表示する。

### 分岐フローA: 履歴が存在しない（基本フロー3から分岐）
3-A. システムは履歴0件を検知する。
4-A. システムはローディング状態を非表示にする。
5-A. システムは空状態メッセージを表示する。

### 例外フローB: 履歴読み込みに失敗する（基本フロー3から分岐）
3-B. システムは履歴読み込みエラーを検知する。
4-B. システムはローディング状態を非表示にする。
5-B. システムはエラーアラートを表示する。

## ユースケース2: 学習履歴の詳細を表示する
### 基本フロー
1. ユーザーは学習履歴セルをタップする。
2. システムは選択した学習回IDの成績詳細画面へ遷移する。

## UI要素
- 学習履歴リスト
- 学習履歴セル
- ローディングインジケータ
- 空状態メッセージ
- エラーアラート

## UI状態
- 履歴一覧データ
- 選択中学習回ID
- ローディング表示状態
- 空状態表示状態
- エラーアラート表示状態

## UIイベント
- 基本フロー1「成績一覧タブを開く」: 成績一覧タブをタップする
- 基本フロー1「学習履歴セルをタップする」: 学習履歴セルをタップする
