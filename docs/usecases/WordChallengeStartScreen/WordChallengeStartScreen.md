# WordChallengeStartScreen UseCases

## ユースケース1: 学習条件を選択する
### 基本フロー
1. ユーザーは単語挑戦画面を表示する。
2. システムは学年選択肢を表示する。
3. システムは学習数選択肢を表示する。
4. ユーザーは学年を選択する。
5. システムは選択中学年を画面に反映する。
6. ユーザーは学習数を選択する。
7. システムは選択中学習数を画面に反映する。

### 分岐フローA: 任意の学習数を入力する（基本フロー6から分岐）
6-A. ユーザーは任意の学習数を入力する。
7-A. システムは入力学習数を画面に反映する。

### 例外フローB: 学習数が不正である（基本フロー6から分岐）
6-B. ユーザーは0以下の学習数を入力する。
7-B. システムは入力値エラーを検知する。
8-B. システムは入力エラー表示を行う。

## ユースケース2: 通常学習を開始する
### 基本フロー
1. ユーザーは学習するボタンをタップする。
2. システムは開始条件を検証する。
3. システムはローディング状態を表示する。
4. システムは選択学年の問題を学習数ぶん読み込む。
5. システムはローディング状態を非表示にする。
6. システムは学習カード画面へ遷移する。

### 例外フローA: 開始条件が不足している（基本フロー2から分岐）
2-A. システムは開始条件不足を検知する。
3-A. システムは入力エラー表示を行う。

### 例外フローB: 問題読み込みに失敗する（基本フロー4から分岐）
4-B. システムは問題読み込みエラーを検知する。
5-B. システムはローディング状態を非表示にする。
6-B. システムはエラーアラートを表示する。

## ユースケース3: 復習学習を開始する
### 基本フロー
1. ユーザーは復習するボタンをタップする。
2. システムは開始条件を検証する。
3. システムはローディング状態を表示する。
4. システムは復習優先度順の問題を学習数ぶん選定する。
5. システムはローディング状態を非表示にする。
6. システムは学習カード画面へ遷移する。

### 例外フローA: 復習対象が不足している（基本フロー4から分岐）
4-A. システムは復習対象不足を検知する。
5-A. システムはローディング状態を非表示にする。
6-A. システムはエラーアラートを表示する。

### 例外フローB: 復習問題選定に失敗する（基本フロー4から分岐）
4-B. システムは復習問題選定エラーを検知する。
5-B. システムはローディング状態を非表示にする。
6-B. システムはエラーアラートを表示する。

## UI要素
- 学年選択セグメント
- 学習数選択セグメント
- 学習数入力フィールド
- 学習するボタン
- 復習するボタン
- ローディングインジケータ
- 入力エラーメッセージ
- エラーアラート

## UI状態
- 選択中学年
- 選択中学習数
- 入力学習数
- ローディング表示状態
- 入力エラー表示状態
- エラーアラート表示状態

## UIイベント
- 基本フロー4「学年を選択する」: 学年選択セグメントをタップする
- 基本フロー6「学習数を選択する」: 学習数選択セグメントをタップする
- 分岐フローA 6-A「任意の学習数を入力する」: 学習数入力フィールドに数値を入力する
- 基本フロー1「学習するボタンをタップする」: 学習するボタンをタップする
- 基本フロー1「復習するボタンをタップする」: 復習するボタンをタップする
