# WordChallengeStartScreen UseCases

## ユースケース1: 学習条件を入力する
### 基本フロー
1. ユーザーは単語挑戦タブを開く。
2. システムは学習開始条件入力フォームを表示する。
3. ユーザーは学年を選択する。
4. システムは選択中学年を表示する。
5. ユーザーは学習数を入力する。
6. システムは入力中学習数を表示する。

### 分岐フローA: 学習数が未入力である（基本フロー5から分岐）
5-A. システムは学習数が未入力であることを検知する。
6-A. システムは入力エラー表示を行う。
7-A. システムは処理を終了する。

### 分岐フローB: 学習数が許容範囲外である（基本フロー5から分岐）
5-B. システムは学習数が許容範囲外であることを検知する。
6-B. システムは入力エラー表示を行う。
7-B. システムは処理を終了する。

## ユースケース2: 学習モードで学習を開始する
### 基本フロー
1. ユーザーは学習開始を要求する。
2. システムはローディング状態を表示する。
3. システムは選択中学年と学習数に合致する出題カードを読み込む。
4. システムはローディング状態を非表示にする。
5. システムは読み込み済み出題カードで学習セッションを開始する。
6. システムは学習セッション画面へ遷移する。

### 分岐フローA: 出題カードが0件である（基本フロー3から分岐）
3-A. システムは出題カードが0件であることを検知する。
4-A. システムはローディング状態を非表示にする。
5-A. システムは空状態メッセージを表示する。
6-A. システムは処理を終了する。

### 例外フローB: 出題カードの読み込みに失敗する（基本フロー3から分岐）
3-B. システムは出題カード読み込み時にエラーを検知する。
4-B. システムはローディング状態を非表示にする。
5-B. システムはエラーアラートを表示する。
6-B. システムは処理を終了する。

## ユースケース3: 復習モードで学習を開始する
### 基本フロー
1. ユーザーは復習開始を要求する。
2. システムはローディング状態を表示する。
3. システムは全学年の誤答履歴を読み込む。
4. システムは学習曲線に基づく復習優先度順で出題カードを選定する。
5. システムはローディング状態を非表示にする。
6. システムは選定済み出題カードで学習セッションを開始する。
7. システムは学習セッション画面へ遷移する。

### 分岐フローA: 復習対象カードが0件である（基本フロー4から分岐）
4-A. システムは復習対象カードが0件であることを検知する。
5-A. システムはローディング状態を非表示にする。
6-A. システムは空状態メッセージを表示する。
7-A. システムは処理を終了する。

### 例外フローB: 復習対象カードの選定に失敗する（基本フロー4から分岐）
4-B. システムは復習対象カード選定時にエラーを検知する。
5-B. システムはローディング状態を非表示にする。
6-B. システムはエラーアラートを表示する。
7-B. システムは処理を終了する。

## UI要素
- 学年選択セグメント
- 学習数入力フィールド
- 学習するボタン
- 復習するボタン
- ローディングインジケータ
- 入力エラー表示
- 空状態メッセージ
- エラーアラート

## UI状態
- 選択中学年
- 入力中学習数
- 入力エラー表示状態
- ローディング表示状態
- 空状態表示状態
- エラーアラート表示状態

## UIイベント
- 基本フロー1「単語挑戦タブを開く」: 単語挑戦タブをタップする
- 基本フロー1「学年を選択する」: 学年選択セグメントをタップする
- 基本フロー1「学習数を入力する」: 学習数入力フィールドへ数値を入力する
- 基本フロー2「学習開始を要求する」: 学習するボタンをタップする
- 基本フロー3「復習開始を要求する」: 復習するボタンをタップする
